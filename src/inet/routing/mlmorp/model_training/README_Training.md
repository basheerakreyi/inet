# MLMORP DNN Training Scripts

This directory contains Python scripts for training Deep Neural Network models for the MLMORP routing protocol using data collected from OMNeT++ simulations.

## Files Overview

- `train_mlmorp_dnn.py` - Main training script
- `example_training.py` - Example script with sample data
- `requirements.txt` - Python dependencies
- `README_Training.md` - This documentation
- `example_model.txt` - Example pre-trained model file

## Installation

### 1. Install Python Dependencies

```bash
pip install -r requirements.txt
```

Required packages:
- pandas >= 1.3.0
- numpy >= 1.21.0
- matplotlib >= 3.4.0
- scikit-learn >= 1.0.0
- tensorflow >= 2.8.0

### 2. Verify Installation

```bash
python example_training.py
```

This will create sample data, train a model, and save the results.

## Usage

### Basic Training

```bash
python train_mlmorp_dnn.py --input ../results/output.csv --output trained_model.txt
```

### Advanced Training Options

```bash
python train_mlmorp_dnn.py \
    --input ../results/output.csv \
    --output trained_model.txt \
    --input-size 6 \
    --hidden-size 12 \
    --epochs 100 \
    --batch-size 32 \
    --learning-rate 0.001
```

### Command Line Arguments

| Argument | Default | Description |
|----------|---------|-------------|
| `--input, -i` | `../results/output.csv` | Input CSV file with collected data |
| `--output, -o` | `trained_model.txt` | Output model file |
| `--input-size` | `6` | Number of input features |
| `--hidden-size` | `12` | Number of hidden neurons |
| `--epochs` | `100` | Number of training epochs |
| `--batch-size` | `32` | Batch size for training |
| `--learning-rate` | `0.001` | Learning rate |
| `--no-plot` | `False` | Disable plotting training history |

## Data Format

The training script expects data in the format generated by the MLMORP protocol's data collection mechanism (`../results/output.csv`):

### CSV Columns (no header)
1. `simTime` - Simulation time
2. `treeId` - Packet tree ID
3. `sourceAddress` - Source IP address
4. `destAddress` - Destination IP address
5. `srcMacAddress` - Source MAC address
6. `destMacAddress` - Destination MAC address
7. `nodeDegree` - Number of neighbors
8. `residualEnergy` - Residual energy capacity
9. `dataRate` - Interface data rate
10. `signalPower` - Signal power (if available)
11. `buffPktNo` - Signal-to-Noise-and-Interference Ratio (if available)

### Features Used for Training
- `residualEnergy` - Normalized residual energy
- `dataRate` - Normalized data rate
- `signalPower` - Normalized signal power
- `nodeDegree` - Normalized node degree
- `buffPktNo` - Normalized buffPktNo

### Target/Label Generation
The script automatically generates binary labels (0/1) based on:
- **Good routing**: `packetDelay < 75th_percentile` AND `residualEnergy > 25th_percentile`
- **Poor routing**: Otherwise

## Model Architecture

The trained model has the following architecture:
- **Input Layer**: 6 neurons (features)
- **Hidden Layer**: 12 neurons with ReLU activation
- **Output Layer**: 1 neuron with Sigmoid activation

### Training Process
1. **Data Loading**: Load CSV data and handle missing features
2. **Preprocessing**: Split data (80% train, 20% test) and normalize features
3. **Model Building**: Create neural network with Xavier/Glorot initialization
4. **Training**: Train with early stopping to prevent overfitting
5. **Evaluation**: Calculate accuracy, classification report, and confusion matrix
6. **Saving**: Save model in C++ compatible format


## Customization

### Modify Target Generation
Edit the `load_data` method in `train_mlmorp_dnn.py` to change how labels are generated:

```python
# Current heuristic
delay_threshold = np.percentile(df['packetDelay'], 75)
energy_threshold = np.percentile(df['residualEnergy'], 25)
y = ((df['packetDelay'] < delay_threshold) & 
     (df['residualEnergy'] > energy_threshold)).astype(int)

# Custom heuristic example
y = (df['packetDelay'] < 0.01).astype(int)  # Simple delay threshold
```

### Add More Features
Modify the features list in the `load_data` method:

```python
# Current features
features = ['residualEnergy', 'dataRate', 'signalPower', 'nodeDegree', 'buffPktNo']

# Add custom features
features = ['residualEnergy', 'dataRate', 'signalPower', 'nodeDegree', 'buffPktNo']
```

### Change Model Architecture
Modify the `build_model` method:

```python
model = keras.Sequential([
    layers.Dense(16, activation='relu', input_shape=(self.input_size,)),  # Larger hidden layer
    layers.Dropout(0.2),  # Add dropout
    layers.Dense(8, activation='relu'),  # Additional hidden layer
    layers.Dense(1, activation='sigmoid')
])
```

## Troubleshooting

### Common Issues

1. **File not found error**
   ```
   Error: File ../results/output.csv not found!
   ```
   - Ensure OMNeT++ simulation has been run from the src/ directory
   - Check file path and permissions

2. **Missing features**
   ```
   Warning: Missing features: ['signalPower', 'buffPktNo']
   ```
   - Default values will be used
   - This is normal if signal tags are not available

3. **Poor model performance**
   - Check data quality and distribution
   - Adjust learning rate or architecture
   - Increase training epochs
   - Review target generation logic

4. **Memory issues**
   - Reduce batch size
   - Use smaller hidden layer
   - Process data in chunks

### Performance Tips

1. **Data Quality**: Ensure sufficient and diverse training data
2. **Feature Engineering**: Consider adding derived features
3. **Hyperparameter Tuning**: Experiment with different architectures
4. **Cross-Validation**: Use k-fold cross-validation for robust evaluation
5. **Regularization**: Add dropout or L2 regularization if overfitting

## Advanced Usage

### Batch Training
```bash
# Train multiple models with different parameters
for hidden_size in 8 12 16; do
    python train_mlmorp_dnn.py \
        --input ../results/output.csv \
        --output model_${hidden_size}.txt \
        --hidden-size $hidden_size
done
```

### Hyperparameter Optimization
```bash
# Grid search example
for lr in 0.001 0.01 0.1; do
    for hidden in 8 12 16; do
        python train_mlmorp_dnn.py \
            --input ../results/output.csv \
            --output model_lr${lr}_h${hidden}.txt \
            --learning-rate $lr \
            --hidden-size $hidden \
            --no-plot
    done
done
```
